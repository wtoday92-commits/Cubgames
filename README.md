# 🎲 Dice Arena

Небольшая браузерная игра на двоих с полем 5×5 и костями. Кооп по коду комнаты
работает **напрямую между браузерами** (P2P через [PeerJS](https://peerjs.com/)),
поэтому свой сервер держать не нужно — игру можно бесплатно разместить на **GitHub Pages**.

## Правила

Поле 5×5 между двумя игроками. У каждого — 4 **личные** кости, плюс 14 **общих**.

- Грани личных костей: жёлтый, зелёный, синий, красный, фиолетовый и **джокер**.
- Грани общих костей — те же цвета, но вместо джокера **белый**.

Ход раунда:

1. **Личные кости.** Каждый втайне кидает свои 4 кости. Можно выбрать любые и
   перебросить **один раз**, затем нажать «Готов». Ход одновременный.
2. **Первый игрок.** Определяется (в 1-м раунде — случайно), рядом с ним значок ①.
3. **Общие кости.** Кидаются все 14. Первый игрок может выбрать до **7** костей и
   перебросить один раз (или сразу «Готов»), затем то же делает второй.
4. **Расстановка общих.** По очереди (начинает **второй** игрок) берёте общую кость
   и ставите в любую пустую клетку — пока не кончатся.
5. **Расстановка личных.** По очереди (начинает **первый** игрок) ставите свои личные
   кости — пока не кончатся. Затем подсчёт очков.

Игра длится **3 раунда** (во 2-м раунде игроки меняются местами и т.д.), затем итог.

### Комбинации

- 3+ костей **одного цвета подряд** в ряду или столбце — это комбинация.
- Комбинация засчитывается, только когда в неё попадает **личная** кость. Владелец —
  тот, кто **последним** поставил в этот ряд/столбец свою личную кость (можно
  «забрать» комбинацию соперника, добавив туда свою кость).
- **Джокер** считается любым цветом. **Белый** — никаким (только мешает).
- Если личная кость входит сразу в две комбинации (ряд и столбец) и соперник
  забирает одну из них — вторая «отключается», пока владелец не активирует её снова.
- Свои комбинации подсвечиваются **синим**, соперника — **красным**.

### Очки

| Длина комбинации | Очки |
|---|---|
| 3 | 1 |
| 4 | 2 |
| 5 | 4 |

## Как запустить локально

Игра — статические файлы, но использует ES-модули, поэтому нужен простой веб-сервер
(через `file://` модули не грузятся):

```bash
python -m http.server 8000
```

Откройте <http://localhost:8000> в двух браузерах/вкладках: один нажимает
«Создать комнату» и передаёт код, второй «Присоединиться» и вводит код.

## Деплой на GitHub Pages

1. Залейте репозиторий на GitHub.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`.
3. Через минуту игра будет доступна по адресу `https://<user>.github.io/<repo>/`.

Так как связь P2P, для игры по интернету достаточно, чтобы оба открыли эту ссылку.

## Тесты

- `test.html` — юнит-тесты логики (комбинации, захват, полный прогон раундов).
- `uitest.html` — проверка, что интерфейс рисуется во всех фазах без ошибок.

Откройте их через локальный сервер; заголовок вкладки покажет `OK N` или `FAIL N`.

## Структура

```
index.html          лобби + контейнер игры
css/styles.css      стили
js/constants.js     константы (цвета, размеры, очки)
js/game.js          чистая логика: состояние, действия, подсчёт очков
js/net.js           P2P-обёртка над PeerJS (комнаты по коду)
js/ui.js            рендер и ввод
js/main.js          связка лобби / сети / игры
```

Хост в сети авторитетен: считает состояние и рассылает его сопернику; гость шлёт
только действия. Это исключает рассинхрон.
